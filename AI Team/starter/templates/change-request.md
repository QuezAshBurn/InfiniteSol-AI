# Project change request | P-NNNN / CR-NNN

- Requester, owner, date, status, change reason and current baseline version
- Proposed change, affected requirements, acceptance criteria and source evidence
- Alternatives including no change, expected benefit, and impact on scope, dates, cost, risks, users and support
- Affected code, diagrams, training, documentation and technical release records
- Recommendation, decision owner, decision date, authority, limits and decision ID
- Revised baseline, test and documentation updates, assigned work and follow-up evidence if approved

Retain the previous baseline until the decision is recorded. Link any affected adoption plan or production release decision separately.
