# Project rules

Use stable IDs for business rules, design constraints and operating limits that apply to the owning project. Link each entry to its business requirement or approved project decision. Record the exact source revision, scope, accountable owner and approval reference. Track verification separately from approval. A source asserted by someone, a prototype outcome or an observed code path may be recorded as evidence with the appropriate status.
