# Tenant rules

Record which approved project rule permits an override, its allowed values, precedence and effective dates. The tenant or business owner confirms the tenant-specific rule and the PM records the applicable approval. Project invariants apply to every tenant. Apply a shared default only when the approved policy and current scoped records support it. Leave unresolved overrides open and pause the affected decision.
