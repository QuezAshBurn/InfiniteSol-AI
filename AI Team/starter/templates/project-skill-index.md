# Project skills and competencies

- Project ID and name
- PM and Solution Architect
- Governing design, business requirements, approved scope and exact revisions
- Updated date and time zone

Copy this template to `Projects/<Project Name>/docs/project-skills.md`. Register only capabilities needed to design, implement, integrate or test an approved project deliverable. Only a written Solution Architect proposal can trigger creation, including adaptation of a company template. The PM records scoped approval before assigning authoring work under the [approved-work policy](../../../AI%20Team/policies/APPROVED-WORK.md). The Solution Architect defines the required job descriptions under the project's `docs/roles/` folder.

The `Skills/` folder contains the project's development bundles and their authorised references and fixtures. Each bundle identifies its owning project, intended use and supported role. A project's bundle is for its own project only. Keep proposed, verified and approved entries distinct. Verify the project identity, registered source and approved revision against any runtime copies before use. Pause the affected task if a required skill is missing or does not match.
